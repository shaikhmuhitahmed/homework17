Bootstrap Utility Classes Example

This page demonstrates the use of Bootstrap utility classes.

1. Background

.bg-primary
.bg-success
.bg-danger
.bg-warning
.bg-info
.bg-light
.bg-dark

2. Colour (Text)

.text-primary This text is primary
.text-success This text is success
.text-danger This text is danger
.text-warning This text is warning
.text-info This text is info
.text-muted This text is muted
.text-dark This text is dark
.text-light This text is light

3. Border

.border (default border)
.border-primary
.border-success
.border-danger
.border-warning
.border-0 (no border)

4. Display

.d-block
.d-inline
.d-inline
.d-flex
.d-none (hidden)

5. Text

.text-start Left aligned text.
.text-center Center aligned text.
.text-end Right aligned text.
.text-uppercase uppercase text
.fw-bold This text is bold.
.fst-italic This text is italic.
.text-decoration-underline Underline text

6. Sizing (Width)

.w-25
25%
.w-50
50%
.w-75
75%
.w-100
100%

7. Overflow

.overflow-auto

This is a long content. When the content is too large, it will add scrollbars automatically.

.overflow-hidden

This content is too large and it will be hidden.

.overflow-visible

This content is visible outside the box. Even if it goes beyond the container.

8. Margin & Padding

Margin (m-*)
.m-1
.m-3
.m-5
Padding (p-*)
.p-1
.p-3
.p-5
